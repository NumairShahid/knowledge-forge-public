# Toadgang builder participation

Welcome, builders! This repository is a public information home, not the private engine development workspace.

Community members who want to work on the core can contact ToadAid through its established Toadgang channels and provide a GitHub username. Access to the private source repository is by explicit invitation and separate terms. Public access here does not grant access there.

Please do not post secrets, internal code, private source copies, vulnerabilities, or personal information in public issues or PRs. Documentation corrections and general questions are welcome. No source-engine submissions are accepted through this public repository during the preview.
