# ToadAid Knowledge Forge — Public Preview

**Status: public documentation preview — no downloadable engine or installer yet.**

Knowledge Forge is ToadAid's provenance-first knowledge system for agents. It is designed to compile source material into inspectable knowledge units, maintain source identity and validation evidence, and let agents load only relevant knowledge without confusing knowledge with memory or execution authority.

## What this repository contains

- A public explanation of the project and its security boundaries
- A plan for independent Codex and Claude compatibility testing
- Information for Toadgang builders who want to participate
- A release-readiness checklist

## What it does **not** contain

- The private Knowledge Forge engine source, private Git history, or build system
- A packaged runtime, runnable installation, downloadable release, or hosted API
- Any license granting rights to undistributed private source code
- Credentials, private registries, production skills, or user data

**Do not attempt to install Knowledge Forge from this documentation repository.** The existing developer installer requires access to the privately maintained source checkout. A public installable distribution will only be announced after its packaging, security, licensing, and independent compatibility reviews are complete.

## Current status and next steps

The private core completed Stage 8 fresh-checkout verification. Independent installation and generic host-integration testing with Codex and Claude is still planned, not yet claimed as passed. The publicly distributable version has not yet been built.

Read [the distribution status](docs/DISTRIBUTION.md), [pilot test plan](docs/INDEPENDENT_PILOT.md), and [builder guide](CONTRIBUTING.md).
